# 3.9.0 runtime notes

Η online παρουσία του Managed MeshCentral node και η τεχνική πρόσβαση είναι ξεχωριστές έννοιες. Η 3.9.0 επιτρέπει μόνο connectivity/availability. Web tunnel, Terminal, Files και Desktop παραμένουν κλειστά μέχρι το μελλοντικό προσωρινό Admin access grant.

Η σταθερή MeshAgent identity αποθηκεύεται ιδιωτικά στο `/data/meshagent-identity/`. Runtime binary, `.msh`, runtime lease και Broker control material παραμένουν ephemeral/memory-only.
